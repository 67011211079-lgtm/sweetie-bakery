# Sweetie Bakery — Go Web App

โปรเจกต์ตัวอย่างเว็บสั่งซื้อเบเกอรี่สำหรับรายวิชา Go Programming Language

## ฟีเจอร์
- สมัครสมาชิกและเข้าสู่ระบบ; เก็บรหัสผ่านด้วย bcrypt
- บทบาท user/admin; ลูกค้าทั่วไปสมัครเองได้เป็น user เท่านั้น
- สินค้าเริ่มต้น 10 รายการ แบ่งเป็นเค้ก ขนมปัง และเครื่องดื่ม
- ฟอร์มสั่งซื้อบันทึกข้อมูลลง SQLite และหน้าแสดงประวัติคำสั่งซื้อของผู้ใช้
- Admin เพิ่ม/แก้ไข/ลบสินค้าและเปลี่ยนสถานะคำสั่งซื้อ
- คำสั่งซื้อของลูกค้าถูกอ่านด้วย `WHERE user_id=?` จึงเห็นเฉพาะออเดอร์ตัวเอง
- ใช้ `html/template` ป้องกัน XSS, parameterized SQL ป้องกัน SQL Injection, ตรวจ input, CSRF token และ security headers
- ใช้ `if err != nil` ตรวจข้อผิดพลาดตามแนวทางในสไลด์ Go

## วิธีรันบน Windows
1. ติดตั้ง Go 1.23 หรือใหม่กว่า
2. แตก ZIP แล้วเปิด CMD/Terminal ในโฟลเดอร์ `sweetie-bakery`
3. รันคำสั่ง:
   ```bash
   go mod tidy
   go run .
   ```
4. เปิด `http://localhost:8080`

## ฐานข้อมูล
SQLite จะสร้างไฟล์ `bakery.db` อัตโนมัติในโฟลเดอร์ที่รันโปรแกรม สามารถตั้งตัวแปรแวดล้อม `DB_PATH` เพื่อระบุไฟล์ฐานข้อมูล และ `PORT` เพื่อกำหนดพอร์ตได้

## นำขึ้นโฮสต์
แอปนี้เป็น Go web service ใช้คำสั่ง build `go build -o app .` และ start `./app` บนโฮสต์ที่รองรับ Go ได้ แต่ SQLite ต้องเก็บไว้บน persistent disk/volume มิฉะนั้นข้อมูลอาจหายเมื่อแพลตฟอร์มรีสตาร์ตหรือ deploy ใหม่ ตรวจเงื่อนไข storage ของโฮสต์ก่อนส่งลิงก์ออนไลน์
